# 研究设计

这个项目研究的不是“某个条件看起来有没有用”，而是同一个事件样本中，某个因子变化后，交易结果是否出现稳定差异。

## 研究流程

### 1. 定义事件

先把交易想法写成事件样本。例如：

- 连板后断板：前一日涨停，当日未涨停
- 单板反包：首板后的第一次断板
- 二连板低竞价：连续两个涨停后，第三个交易日竞价低于某个区间

事件定义确定后，不在同一次实验中随意改变。

### 2. 建立基准

每个实验先跑一个基准方案，明确样本区间、买入时点、卖出时点和交易成本。后续分组都以这个基准为参照。

基准的作用是控制变量。没有基准时，容易把样本变化误认为因子有效。

### 3. 单因子扰动

每次只改变一个因子，例如：

- 只改变第三日竞价区间
- 只改变第二天成交额区间

其他条件尽量保持不变。这样比较的是该因子本身，而不是一组新条件。

### 4. 评价指标

同时看以下指标：

- 交易数
- 净胜率
- 平均净收益率
- 平均盈利和平均亏损
- 盈亏比
- 净利润因子
- 累计收益金额
- 最大并发持仓和周转资金

只看胜率不够，只看平均收益也不够，需要结合样本量和资金效率。

### 5. 市场解释

统计结果需要对应到市场行为：

- 竞价涨幅反映开盘承接和隔夜预期
- 成交额反映流动性、关注度和资金参与程度
- 实体涨幅反映日内真实强弱
- 连板层级反映市场辨识度和情绪位置

如果统计上有效，但在交易逻辑上讲不通，就标记为待验证，不直接采用。

## 结果分级

- 正向：平均收益、胜率和资金效率至少有两项改善，样本量可接受
- 中性：指标接近打平，缺少必要条件
- 负向：平均收益或资金效率明显变差
- 样本不足：统计值为正，但分组交易数太少，不能作为结论

## 防止过拟合

- 先定基准，再一个一个改因子
- 负向结果也留着，不挑好看的留下
- 样本量和数据限制都记下来
- 分清日线、分钟线、Tick/L1/L2 各自能回答什么问题
- 现在这段只是研究样本，不能顶替样本外验证

## 当前研究的边界

当前统计只来自代码回测，没有混入人工实盘结果。题材强度、市场情绪和个股相对强度可以解释交易逻辑，但不作为已经验证的量化因子。

卖出价使用卖出日均价，也就是成交额除以成交量，并扣除滑点。它代表全天分批卖出的统一执行基准，不代表人工一定能在均价成交；实盘卖点与回测卖点不能混为一谈。

历史 Tick、L1/L2 和封单金额目前没有接入。开板次数用 5 分钟线近似，无法识别同一分钟内反复打开。项目不把缺失字段伪造成精确因子。
